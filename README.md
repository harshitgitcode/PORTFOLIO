# Harshit — Internship Portfolio

A dependency-free, responsive portfolio for Harshit, a first-semester BCA student specializing in AI/ML.

## Customize

Open `index.html` and replace the `TODO` values in the contact section:

- `TODO_ADD_YOUR_EMAIL@example.com`
- `TODO_ADD_YOUR_GITHUB`
- `TODO_ADD_YOUR_LINKEDIN`
- `TODO: Add your city`

The semester subjects, project cards, and learning journey are written as real, easy-to-edit content. Projects are intentionally labeled **In progress** or **Planned** until there is finished work to showcase.

## Run locally

Because this is a static site, open `index.html` directly in a browser or serve the folder with any static file server.

## Publish for mobile access

The repository includes a GitHub Pages workflow in `.github/workflows/deploy-pages.yml`. Merge these files into the `main` branch, then enable **Settings → Pages → GitHub Actions** in the repository. GitHub will publish the site at:

`https://harshitgitcode.github.io/PORTFOLIO/`
